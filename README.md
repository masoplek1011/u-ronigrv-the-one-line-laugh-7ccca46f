A tiny deterministic program that writes one funny line — a single sentence of at most 200 characters — to `entry.txt`. The line is about a sleep tracker whose helpfulness backfires: it praises a good night's sleep, then ruins it.

## Run it

```sh
node main.ts
```

This writes `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program uses only the Node standard library, runs offline, and always produces the same output.
